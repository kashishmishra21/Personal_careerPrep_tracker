# Career Prep — Personal Career Preparation Tracker

A lightweight personal career preparation tracker designed to organize and track my journey toward becoming a **job-ready Full-Stack Developer**.

Instead of managing DSA, interview preparation, projects, certifications, job applications, and daily study goals across multiple places, this application brings everything into one dashboard.

## 🚀 Features

* 📅 Daily preparation plan
* ✅ Task completion tracking
* 🔥 Daily study streak
* 📊 Progress tracking
* 🗓️ GitHub-style activity calendar
* 💻 DSA preparation tracker
* 🎯 Technical interview preparation
* 🧑‍💼 HR interview preparation
* ⚛️ MERN Stack interview preparation
* 🛠️ Project tracking
* 📜 Certificate tracking
* 🏆 Hackathon tracking
* 💼 Job application tracking
* 📝 LinkedIn & GitHub activity tracking
* 🌙 Dark/Light mode
* 💾 Local data persistence using localStorage
* 📱 Responsive design

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript
* HTML5
* CSS3
* Browser localStorage

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kashishmishra21/Personal_careerPrep_tracker.git
```

### 2. Navigate to the project

```bash
cd Personal_careerPrep_tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal.

## 🎯 Purpose

This project was created to solve a personal problem:

> **I was spending too much time deciding what to study instead of actually studying.**

The goal of Career Prep is to create a structured system where I can track preparation consistently and see measurable progress over time.

## 📈 Progress Philosophy

Progress in this application is based on **actual task completion**, rather than manually entering an arbitrary percentage.

The activity calendar and streak are intended to reflect consistent preparation.
